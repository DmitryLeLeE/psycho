# Кабинет восприятия

Том IV серии [«Атласы невидимого»](https://dmitrylelee.github.io/atlas/) · 159.937.
Интерактивный научно-популярный атлас о психологии восприятия: иллюзии контраста,
формы, движения и размера, двойственные фигуры, генератор симметричных клякс
и «горилла» Саймонса и Шабри.

Статичный сайт без сборки: `index.html`, `style.css`, `main.js`. Все стимулы
рисуются на Canvas 2D и SVG, без фреймворков, видео и WebGL.

- Движущиеся стимулы запускаются только по кнопке; есть режим «без движения»,
  он же включается автоматически при `prefers-reduced-motion`.
- Ответы (протокол, кляксы) хранятся только в `localStorage` браузера.

Локально: `python3 -m http.server` и открыть http://localhost:8000.

Это научно-популярный материал, а не психологическая диагностика.
